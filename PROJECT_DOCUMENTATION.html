1. Executive Summary

ForenSight is a database-driven Digital Forensics Investigation & Evidence Management Platform. Standard full-file hashes (e.g. SHA-256) function only as binary indicators: they show if an artifact was changed, but cannot reveal where. ForenSight introduces deterministic 4096-byte Merkle tree block slicing to pinpoint the exact physical byte offsets of tampering, an autonomous 5-part forensic diagnostic engine, an append-only SHA-256 hash-chained custody ledger, and automated compliance reporting under Section 63(4) of the Bharatiya Sakshya Adhiniyam, 2023 (BSA).

3. Core Forensic Methodologies

  • Stream-Buffered Multi-Hashing ($O(1)$ RAM): Calculates MD5, SHA-1, and SHA-256 concurrently using 64 KB buffers, preventing Out-Of-Memory crashes on multi-GB disk images.
  • 4096-Byte Merkle Tree Slicing: Partitions file into 4KB blocks: [i * 4096, (i + 1) * 4096 - 1]. Comparing candidate blocks against baseline isolates exact modified sectors.
  • 5-Part Diagnostic Engine:
    1. Multi-Hash Divergence: Cross-algorithm integrity check.
    2. Magic Byte Analysis: Detects file extension spoofing (e.g., EXE renamed to PDF).
    3. EXIF & Telematics: Camera serial numbers, GPS coordinates, Photoshop author tags.
    4. Error Level Analysis (ELA): Recompression delta visualized via OpenCV Jet colormaps.
    5. Temporal Paradoxes: Modified before creation, future dates, anachronisms.
  • Append-Only Custody Ledger: EventHash_k = SHA-256(EventHash_{k-1} || Payload_k). Modifying any past record breaks the chain.
  • Integrity Watchdog Daemon: Scans files every 30 seconds; sends real-time Server-Sent Events (SSE) upon any disk alteration.
  • Statutory Admissibility: Auto-generates certified PDF reports meeting BSA 2023 Section 63(4) and US FRE 902(13/14).

5. Review Defense Q&A Cheat Sheet

Q: Why Merkle Trees instead of single SHA-256?
A: SHA-256 is binary—it only indicates whether a file changed. Slicing into 4096-byte blocks allows ForenSight to pinpoint the exact physical byte offsets of tampering.
Q: How is Chain of Custody secured against DBA tampering?
A: It uses SHA-256 parent-child hash chaining. Any modification or deletion of past records breaks the hash verification at that index immediately.
Q: What legal standard does the PDF certificate satisfy?
A: Section 63(4) of the Bharatiya Sakshya Adhiniyam, 2023 (BSA) (superseding Section 65B of Indian Evidence Act) and ISO/IEC 27037:2012.
